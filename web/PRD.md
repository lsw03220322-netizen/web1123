## 1. 프로젝트 개요 (Project Overview)

### 1.1 배경 및 기획 의도
- **문제점:** 초등학교 5~6학년 수학 교과과정의 '입체도형과 전개도' 단원은 많은 학생이 가장 어려워하는 영역입니다. 2D 평면 교과서 그림만으로는 3D 공간으로 접혀 올라가는 과정을 머릿속으로 시각화(심상화)하기 어렵습니다.
- **해결책:** '스트링 텐션 힌지(String Tension Hinge)' 메커니즘을 적용하여 **"끈을 당기면 평면 전개도가 즉시 3D 입체도형으로 일어나는"** 실제 물리 교구의 경험을 웹 인터랙션(드래그, 슬라이더, 3D 렌더링)으로 생생하게 디지털화합니다.
- **목표:** 공식 암기 위주의 학습에서 벗어나, 손가락 터치와 마우스 드래그를 통해 평면(2D)과 입체(3D)의 유기적 상관관계를 오감으로 체험할 수 있는 에듀테크 웹 플랫폼을 구축합니다.

### 1.2 핵심 가치 (Value Proposition)
1. **직관적 3D 조작성:** 끈을 당기는 가상 손잡이(PULL 탭) 인터랙션으로 전개도가 접히고 펴지는 연속적인 폴딩 과정을 360도로 관찰.
2. **수학적 원리의 시각화:** 밑면과 옆면의 일치 관계, 원기둥의 원주($2\pi r$)와 가로 길이 관계 등을 파라미터 조작을 통해 실시간 증명.
3. **체험형 학습 & 오류 발견:** 11가지 정육면체 전개도 검증 및 '오답 전개도' 실험을 통해 입체도형이 완성되지 않는 이유를 자기주도적으로 학습.
4. **온·오프라인 연계(O2O):** 웹 체험에 그치지 않고 가정/학교에서 직접 만들어 볼 수 있는 DIY 도안 커스텀 출력 기능 제공.

## 4. 세부 기능 요구사항 (Functional Requirements)

### 4.1 [핵심] 가상 스트링 텐션 3D 뷰어 (Virtual String Tension 3D Viewer)
- **4.1.1 5대 입체도형 모델링 및 전개도 매핑:**
  - **직육면체 (Cuboid):** 십자형 전개도, 마주보는 면(3쌍) 색상 동기화.
  - **삼각기둥 (Triangular Prism):** 중앙 직사각형 3개 + 상하 정삼각형 2개, ㄷ자형 접힘.
  - **정육면체 (Cube):** 대표 지그재그형 전개도, 6개 합동 정사각형.
  - **원기둥 (Cylinder):** 평면 직사각형이 곡면 실린더로 둥글게 말려드는 벤딩(Bending) 애니메이션.
  - **육각뿔 (Hexagonal Pyramid):** 바닥 정육각형 + 6개 이등변삼각형이 중앙 뿔 꼭짓점으로 모이는 수직 견인 애니메이션.
- **4.1.2 인터랙티브 PULL 텐션 컨트롤:**
  - 화면 하단에 실제 교구처럼 디자인된 **'PULL' 손잡이 탭** 제공 (드래그하여 아래로 당기거나 터치 슬라이더 지원).
  - 텐션 게이지(0% ~ 100%): 
    - `0%`: 바닥에 100% 완전 평면으로 펼쳐진 전개도(2D)
    - `1% ~ 99%`: 실을 당기며 각 면이 회전축을 따라 점진적으로 접혀 올라가는 과정
    - `100%`: 모서리가 완벽히 맞닿아 자립한 3D 입체도형
  - 실 궤적 시각화: 펀칭 구멍을 통과하는 노란색/빨간색 가상 스트링 라인 렌더링.
- **4.1.3 3D 카메라 & 시각 효과:**
  - 마우스 드래그 / 모바일 터치를 통한 360도 자유 궤도 회전(OrbitControls) 및 확대/축소.
  - 면 투명도 조절(X-Ray 모드): 도형 내부 모서리와 겨냥도 선 관찰 가능.
  - 요소 분리 분석 토글: 면(Face), 모서리(Edge), 꼭짓점(Vertex)을 각각 색상별로 하이라이트하고 개수를 실시간 카운팅.

### 4.2 수학 원리 탐구 랩 (Math Principle Lab)
- **4.2.1 원기둥 전개도 원주($2\pi r$) 실시간 인터랙션:**
  - 밑면 반지름 $r$ (예: 2.5cm) 슬라이더 조절 시, 밑면 둘레($2 \times \pi \times r \approx 15.7\text{cm}$)와 옆면 직사각형 가로 길이가 실시간 연동.
  - 오버랩(여유분 2.3cm) 영역을 시각적으로 점선 표시하여 실제 제작 시 풀칠/겹침 구간에 대한 수학적 이유 설명.
- **4.2.2 정육면체 11가지 전개도 라이브러리:**
  - 정육면체가 성립하는 11가지 패턴(1-4-1형 6종, 2-3-1형 3종, 2-2-2형 1종, 3-3형 1종) 선택 기능.
  - 각 패턴별로 '스트링을 어디에 꿰어야 완성되는지' 최적의 타공점 표시.

### 4.3 인터랙티브 놀이 및 퀴즈 (Gamified Activities)
- **4.3.1 [활동 1] 스피드 전개도 맞히기 퀴즈:**
  - 무작위 전개도를 제시하고, 입체도형 4지선다 선택.
  - 선택 후 "줄 당겨서 확인하기"를 누르면 전개도가 3D로 조립되며 정답 여부 및 축하 효과 연출.
- **4.3.2 [활동 2] 만나는 모서리 & 꼭짓점 짝짓기:**
  - 평면 전개도에서 접었을 때 서로 맞닿는 모서리/꼭짓점을 클릭하여 같은 색상 핀으로 연결.
  - 끈을 당겨 실제로 두 점/선이 만나는지 3D로 실시간 검증.
- **4.3.3 [활동 3] 오답 전개도 실험실:**
  - 면이 겹치거나(Overlap) 뚜껑이 열린 상태로 완성되지 않는 잘못된 전개도 3~4종 제공.
  - 끈을 당겼을 때 면끼리 충돌하거나 구멍이 뚫리는 오류 애니메이션을 보여주고 이유 설명.

### 4.4 DIY 제작 매뉴얼 & 도안 다운로드 센터
- **4.4.1 4단계 인터랙티브 제작 가이드:**
  - STEP 1 도안 작도 (180~220g 도화지 안내)
  - STEP 2 접는 선 칼선 내기 (칼등 누름선 팁)
  - STEP 3 타공하기 (5~8mm 안쪽 펀칭 규격 안내)
  - STEP 4 실 꿰기 & PULL 탭 제작 (실 꿰는 순서도 애니메이션)
- **4.4.2 도안 인쇄/내보내기 (Print/Export):**
  - A4 용지에 최적화된 SVG 기반 도안 뷰어 및 브라우저 원클릭 인쇄(`Ctrl+P` 최적화 CSS).
  - 접는 선(파선), 자르는 선(실선), 펀치 타공점(원형 표시) 규격화.

### 4.5 초등 교육과정 연계 뷰 (Curriculum Map)
- 5학년 2학기 (5단원 직육면체), 6학년 1학기 (2단원 각기둥과 각뿔), 6학년 2학기 (6단원 원기둥, 원뿔, 구) 성취 기준에 맞춘 단원별 필터 제공.
- 수업 시간에 바로 띄워놓고 설명할 수 있는 '교사용 프리젠테이션 모드(단순화된 UI, 큰 글씨)'.

## 5. 기술 스택 및 아키텍처 제안 (Technical Stack & Architecture)

| 구분 | 추천 기술 | 선정 이유 |
| :--- | :--- | :--- |
| **코어 런타임** | HTML5, Modern JavaScript (ES6+), CSS3 | 브라우저 호환성 및 설치 없는 즉시 실행, 경량 배포 가능 |
| **3D 그래픽 엔진** | **Three.js** | 웹 기반 3D 전개도 폴딩, 계층적 피벗(Pivot) 회전 및 벤딩 구현에 가장 최적화 |
| **3D 컨트롤** | Three.js `OrbitControls` | 마우스 드래그 및 모바일 멀티터치 회전/줌 기본 지원 |
| **애니메이션 & 인터랙션** | **GSAP (GreenSock)** 또는 Three.js 렌더 루프 | PULL 슬라이더 수치(0~1)와 3D 본/메시 회전 각도($0^\circ \sim 90^\circ$)의 정밀한 선형 보간(Lerp) |
| **UI 프레임워크 / 스타일** | **Tailwind CSS** (또는 모던 CSS 컴포넌트) | 깔끔하고 반응형에 최적화된 키즈/에듀 감성의 모던 UI 디자인 |
| **도안 렌더링/인쇄** | **SVG (Scalable Vector Graphics)** | 해상도 저하 없는 완벽한 벡터 인쇄 및 프린터 출력 치수(mm 단위) 정확도 보장 |
